Official releases and platform installers

Install on Windows

  1. Open Command Prompt and download the installer for the current release from the official release page.
  2. Run the installer and follow its prompts. Native compilation also requires a C compiler and Windows build tools; review the installer output for prerequisites.
  3. Open a new terminal and verify the installation with koka --version.
curl -sSL -o %TEMP%\install-koka.bat https://github.com/koka-lang/koka/releases/download/v3.2.9/install.bat
%TEMP%\install-koka.bat

Install on macOS or Linux

Use the official installation script linked from the current Koka release page. Check its documented prerequisites and verify with koka --version.
